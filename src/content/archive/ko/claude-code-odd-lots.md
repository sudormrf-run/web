## Claude Code란 무엇인가

노아 브라이어(Alpehic 공동 창업자)는 2022년부터 AI 코딩 도구를 사용해왔다. GitHub Copilot에서 시작해 GPT-3 API, Cursor를 거쳐 Claude Code까지 발전 과정을 직접 경험했다.

Claude Code의 핵심 차별점:

- [13:16] 첫째: 컴퓨터에서 **파일을 읽고 쓸 수 있다** (로컬 I/O 권한)
- [13:19] 둘째: **유닉스를 다룰 수 있다** (Bash/Unix 명령 접근)
- [13:32] 모델이 인터넷으로 학습됐고, 유닉스 명령을 놀라울 정도로 잘 사용한다
- [14:38] 파일 쓰기 권한으로 **메모리를 외부화**해 LLM의 무상태 문제를 극복

> "Claude Code의 특별한 점은 압축이 아니라 컴퓨터에서 파일을 쓰고 읽을 수 있는 능력입니다."

## 메모리 외부화와 유닉스 조합

- [17:23] "앞으로의 세션을 위해 이 점을 꼭 기억하라"고 지시하면 파일로 저장
- [17:39] 메모리가 **"스킬"**이라는 형태로 기록되어 모든 세션에서 유지
- [18:24] 유닉스 도구들은 **한 가지 일만 하고 모두 조합 가능**
- [18:45] 파이프 하나로 한쪽에서 다른 쪽으로 출력을 넘기는 강력한 조합

## 경쟁 도구와 철학 차이

Claude Code vs Codex의 근본적 차이:

- [22:14] **Codex**: 과제를 주면 스스로 수행하는 에이전트 초점
- [22:25] **Claude Code**: 함께 일하는 **페어 프로그래머** 설계

권한 모델의 중요성:

- [21:36] Claude Code는 **아주 세밀한 권한 관리 모델**을 갖추고 있음
- [21:40] "이번 한 번만 허용" 또는 "항상 허용" 선택 가능
- [21:53] "dangerously skip permissions" 플래그를 **YOLO mode**라고 부름

> "저는 항상 계획 모드에서 시작합니다. 계획을 세우고 주고받으면서 많은 시간을 씁니다."

## 엔지니어 워크플로의 변화

- [24:53] Claude Code는 워크플로를 **"가능한 한 완전히 바꾼다"**
- [25:02] 지난 3개월간 직접 쓴 코드는 "몇백 줄" 정도
- [25:02] 대부분 **에이전트들의 집합을 관리하는 관리자** 역할
- [25:27] 이제 **조율의 문제**가 되었음
- [26:42] 코드를 직접 쓰는 사람이 아니라 **시스템을 설계하는 사람**으로 변화

## 바이브 코딩과 코딩 리터러시

- [31:46] Claude Code 팀조차 자신들이 **코드를 얼마나 적게 쓰는지** 이야기
- [32:12] 아홉 살 아이가 바이브 코딩으로 산타를 위한 웹사이트를 만든 사례
- [32:52] 앤스로픽에서는 **모든 코드를 여전히 사람이 검토**
- [32:58] 놀라운 점: 이런 세션을 **한 번에 다섯 개씩** 병렬로 돌림

> "진정한 우아함은 절제입니다. 최고의 엔지니어들은 가장 적은 코드를 씁니다."

## 기업과 채용에 미치는 영향

"퍼지 인터페이스" 개념:

- [34:53] 모델은 어떤 데이터든 다른 형태로 **변환/번역**하는 데 탁월
- [34:22] 모델이 **65퍼센타일 수준**의 결과를 만들어냄
- [34:30] 백만 토큰당 1.50달러 vs 연봉 수십만 달러의 **트레이드오프**
- [35:28] 조직에서 가장 중요한 역할 중 하나가 **번역 작업**

## SaaS 산업의 위협

구축 vs 구매의 진자추:

- [37:09] **완전히 한쪽(구축)으로 흔들렸다**
- [36:39] "소프트웨어가 꽤 망한 것 같다. 적어도 많은 부분이"
- [38:35] 많은 영역에서 소프트웨어가 **데이터베이스를 감싼 래퍼**에 불과

CRM(Salesforce) 사례:

- [39:07] 본질은 영업사원들이 **비정형 데이터를 정형 데이터로 변환**하는 것
- [39:18] AI는 비정형 데이터를 원천에서 직접 가져오는 데 **매우 능숙**
- [39:50] 그 전체를 **통째로 없앨 수 있는 능력**이 생김

> "엔터프라이즈 소프트웨어의 비밀은 아무도 그것을 사람들이 바라던 방식대로 사용하지 않았다는 것입니다."

## 가격과 락인 전략

가격 구조:

- [44:38] 월 200달러 플랜 결제 (Max 플랜)
- [45:59] Opus 4.5 가격: 입력 토큰 100만 개당 1.50~2달러
- [46:17] Gemini 3 Pro, ChatGPT 5.2 모두 **같은 가격대**

락인의 어려움:

- [51:13] AI 도구 간 전환이 **매우 옮겨 다니기 쉽다**
- [51:17] 'Claude mode' 파일을 다른 도구에서 열어도 이어서 작업 가능
- [52:06] 락인은 **양쪽으로 다 작용**함

> "지금 쓰는 모델이 우리가 써본 것 중 가장 형편없는 모델입니다."
