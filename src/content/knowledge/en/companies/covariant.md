## Overview

Covariant is an AI robotics company founded in October 2017 (originally as Embodied Intelligence), developing general-purpose AI for robots. The company launched from stealth on January 29, 2020. It focuses on logistics and warehouse automation, with deployments at major global retailers and logistics companies across 15+ countries.

| Item | Details |
|------|---------|
| Headquarters | Emeryville, California |
| Founded | October 2017 |
| Original Name | Embodied Intelligence |
| Stealth Launch | January 29, 2020 |
| Total Funding | $222M+ |
| Key Customers | GXO Logistics, Otto Group, McKesson, Crate & Barrel |

## Core Technology

### Covariant Brain

General-purpose AI for robot vision, reasoning, and action:

```
[Visual Input] → Covariant Brain → [Robot Action]
                    ↓
         - Object Recognition
         - Grasp Planning
         - Error Recovery
```

### RFM-1 (Robotics Foundation Model 1)

Announced March 2024, an 8 billion parameter multimodal model:

| Feature | Description |
|---------|-------------|
| Parameters | 8B |
| Training Data | Text, images, video, robot actions, sensor data |
| Capabilities | Physical world understanding, natural language programming, self-reflection |

## Research Contributions

### Key Ideas

1. **General-Purpose Robot AI**: Single model for diverse tasks
2. **Real-World Learning**: Learning from actual deployment data
3. **Scalable Architecture**: Foundation model approach to robotics

### Influence on Field

- Early commercial success of robot learning
- Demonstration of foundation model viability for robotics
- Bridge between academic research and industry deployment
