## Overview

Unitree Robotics(杭州宇树科技有限公司)는 중국의 로봇 하드웨어 제조사로, 저렴하면서도 고성능인 사족보행 로봇과 휴머노이드를 생산합니다. $13,500부터 시작하는 휴머노이드 G1과 $5,900 R1으로 가격 혁신을 이끌고 있습니다.

| 항목 | 내용 |
|------|------|
| 본사 | 항저우, 중국 |
| 설립 | 2016년 8월 26일 (왕싱싱 창업) |
| CEO | Wang Xingxing (왕싱싱, 1990년생) |
| 기업가치 | Series C: ~$1.3B (2025.06), IPO 목표: $7B |
| 핵심 제품 | Go2, B2, G1, H1, H2, R1 |

---

|------|------|------|
| Go2 Air | 소비자용 | ~$1,600 |

## G1 휴머노이드

### 스펙

| 항목 | 수치 |
|------|------|
| 높이 | 127cm (8세 아동 크기) |
| 무게 | 35kg |
| 자유도 | 23-43 DoF (구성에 따라) |
| 최대 보행속도 | 2m/s (4.5 MPH) |
| 센서 | 3D LiDAR (LIVOX MID-360), Intel RealSense D435, 4-mic array |
| 손 | Dex3 힘 제어 손 (EDU Ultimate) |
| 컴퓨팅 | NVIDIA Jetson Orin (EDU, 100 TOPS) |
| 가격 | Base $13,500 / EDU Standard $43,500 |

### 특징

- **접이식 디자인**: 컴팩트하게 운반 가능
- **저렴한 가격**: $13,500부터 (기존 휴머노이드 대비 혁신적)
- **강화학습 기반**: 이미테이션/강화 학습 적용
- **페이로드**: 팔당 최대 3kg

## H1 휴머노이드

### 스펙

| 항목 | 수치 |
|------|------|
| 높이 | 180cm |
| 무게 | 47kg |
| 최대 토크 | 360N.m |
| 달리기 속도 | 3.3m/s (세계 기록) |
| 가격 | ~$90,000 |

### 성과

- **세계 최고속 휴머노이드**: 3.3m/s (7.38 mph) 보행 기록 - 기네스 세계 기록 (2024.03)
- **2025 World Humanoid Robot Games 4관왕** (베이징, 400m/1500m/100m 허들/4x100m 릴레이)
- 1500m 세계 기록: 6분 34.40초
- 경기 중 최고 속도: 4.78m/s (내부 테스트 5m/s 초과)
- 복잡한 지형 자율 보행
- 유압 없이 백플립 성공 (2024.03)

## R1 휴머노이드

### 스펙

| 항목 | 수치 |
|------|------|
| 높이 | 121cm |
| 무게 | 25kg |
| 자유도 | 26 DoF |
| 센서 | 바이노큘러 카메라, 4-mic array |
| 배터리 | 교체 가능, ~1시간 |
| 가격 | ~$5,900 (39,999 위안) |
| 출시 | 2025년 7월 |

### 특징

- **최저가 풀사이즈 휴머노이드**: $5,900으로 개인 개발자/교육용 접근성 확보
- **운동 특화**: 물구나무, 카트휠, 앞구르기, 쿵푸 동작 가능
- **경량 설계**: 25kg으로 R&D 테스트에 적합
- **타겟**: 개인 개발자, 초기 연구팀, 교육 시장

## H2 휴머노이드

### 스펙

| 항목 | 수치 |
|------|------|
| 높이 | 180cm |
| 무게 | 70kg |
| 자유도 | 31 DoF (3-DoF 허리, 2-DoF 목) |

| 배송 | 2026년 4월 예정 |

### 특징

- **H1 후속작**: 더 많은 자유도와 향상된 조작 능력
- **두 가지 버전**: Commercial (배포용), EDU (연구용, 2차 개발 가능)
- **댄스/쿵푸 동작**: 유연한 허리와 목 관절로 자연스러운 움직임
- **정밀 조작**: 고급 로봇 손으로 정교한 물체 조작

## 보안 취약점 (2025.09 공개)

*아래는 보안 연구자 Andreas Makris와 Kevin Finisterre가 2025년 9월 공개한 내용.*

**CVE-2025-60250 (UniPwn)**:
- **취약점**: BLE Wi-Fi 설정 인터페이스의 하드코딩된 AES 키
- **심각도**: 중간 (root 권한 탈취 가능)
- **영향 범위**: Go2, B2, G1, H1, R1
- **위험**: 웜(Worm) 형태 확산 가능 - 감염된 로봇이 주변 Unitree 로봇 자동 감염
- **데이터 전송**: G1이 5분마다 중국으로 데이터 전송 확인
- **대응**: Unitree가 2025.09.29 성명 발표, 펌웨어 업데이트 배포 중
- **권장 조치**: 격리된 Wi-Fi 네트워크 사용, Bluetooth 비활성화
